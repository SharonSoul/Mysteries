# Documentary Video Editing

This skill governs local, automated video editing, motion graphics, and audio mastering using **FFmpeg** on Windows.

## Video Format Specifications

### Long-Form Documentaries
- **Resolution**: 1920 x 1080 (16:9 Horizontal)
- **Framerate**: 30.0 fps (or 24.0 fps cinematic)
- **Video Codec**: H.264 (`h264_nvenc` for NVIDIA GPU, fallback to `libx264`)
- **Pixel Format**: `yuv420p`
- **Audio Codec**: AAC, 192 kbps stereo, 44.1 kHz, `-14 LUFS` EBU R128

### YouTube Shorts
- **Resolution**: 1080 x 1920 (9:16 Vertical)
- **Duration**: 40 to 90 seconds
- **Image Framing**: Scale and center crop, or blurred background fit for archival horizontal photos.

## Core FFmpeg Automation Pipelines

### 1. Ken Burns Pan & Zoom (Archival Photos)
```bash
# Slow Push-in (1.0x to 1.15x over 5 seconds)
ffmpeg -loop 1 -i photo.jpg -vf "scale=8000:-1,zoompan=z='min(zoom+0.0015,1.25)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=150:s=1920x1080:fps=30" -t 5 -c:v libx264 -pix_fmt yuv420p scene_push.mp4
```

### 2. Vertical Shorts Framing (Blurred Backdrop)
```bash
ffmpeg -loop 1 -i landscape_photo.jpg -filter_complex "[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,boxblur=20:5[bg];[0:v]scale=1080:1920:force_original_aspect_ratio=decrease[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2" -t 5 -c:v libx264 -pix_fmt yuv420p short_scene.mp4
```

### 3. Audio Mixing with Dynamic Sidechain Ducking
```bash
ffmpeg -i narration.wav -i background_music.wav -filter_complex "[1:a]volume=0.30[music_bed];[music_bed][0:a]sidechaincompress=threshold=0.08:ratio=4:attack=50:release=350[ducked_music];[0:a][ducked_music]amix=inputs=2:duration=first:dropout_transition=2[mixed]" -map "[mixed]" -c:a aac -b:a 192k mixed_audio.m4a
```

### 4. YouTube Loudness Mastering (-14 LUFS)
```bash
ffmpeg -i mixed_audio.m4a -af "loudnorm=I=-14:TP=-1.0:LRA=7" -c:a aac -b:a 192k mastered_audio.m4a
```

### 5. Burning High-Contrast Whisper Subtitles
Use the SRT subtitles generated by local Whisper from the approved narration audio:
```bash
# Vertical Shorts Style (MarginV=140 to avoid bottom UI buttons/captions)
ffmpeg -i video_clean.mp4 -vf "subtitles=captions.srt:force_style='FontName=Arial Black,FontSize=22,PrimaryColour=&H0000FFFF,OutlineColour=&H00000000,BorderStyle=3,Outline=2.5,Shadow=1,Alignment=2,MarginV=140'" -c:v libx264 -c:a copy final_output.mp4
```
